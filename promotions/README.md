# 🏷️ מבצעים — עדכון חודשי בפקודה אחת

מודול לבניית **קובץ מבצעים חודשי מסודר** (Excel) מתוך רשימה פשוטה, בלי לתחזק
טבלה מסובכת ידנית כל חודש.

## הרעיון בשורה אחת

כל חודש אתה נותן **רשימה קטנה** (שם / מפתח פריט / אחוז מבצע) + **קובץ קטלוג
מוצרים** שאתה מייצא מחשבשבת/H-BI. פקודה אחת מעשירה הכל לפי מפתח פריט
(ברקוד, מחיר, קטגוריה), משווה לחודש הקודם, וכותבת אקסל צבעוני מוכן.

## הצביעה

| צבע | סטטוס | משמעות |
|-----|-------|--------|
| 🟩 ירוק | נשאר | היה בחודש הקודם וגם החודש |
| 🟨 צהוב | חדש | חדש החודש, לא היה קודם |
| 🟥 אדום | ירד | היה בחודש הקודם, לא החודש |

## מה צריך להכין (3 קבצים)

1. **רשימת המבצעים של החודש** — CSV/Excel עם 3 עמודות:
   `שם מוצר`, `מפתח פריט`, `מבצע`. (תבנית: `templates/מבצעים_חודש.csv`)
2. **קטלוג המוצרים** — ייצוא מחשבשבת/H-BI. צריך לפחות עמודת מפתח פריט;
   הסקריפט מזהה אוטומטית ברקוד/מחיר/קטגוריה/שם אם קיימים.
3. **רשימת החודש הקודם** (אופציונלי) — אותו פורמט כמו (1). בלעדיה הכל ייחשב
   "חדש" (אין מול מה להשוות).

## איך מריצים

```bash
python -m promotions.build_promos \
    --current   promotions/examples/מבצעים_אוקטובר_דוגמה.csv \
    --catalog   promotions/examples/קטלוג_מוצרים_דוגמה.csv \
    --previous  promotions/examples/מבצעים_ספטמבר_דוגמה.csv \
    --out       "data/מבצעים אוקטובר מסודר.xlsx" \
    --month     אוקטובר
```

הפלט: קובץ אקסל מסודר עם צביעה, מיון (נשאר → חדש → ירד), וכותרות מוקפאות.

## העמודות בפלט

`סטטוס` · `שם מוצר` · `מפתח פריט` · `ברקוד` · `מחיר` · `קטגוריה` ·
`מבצע <חודש>` · `מבצע קודם` (למי שירד) · `בקטלוג` (מסמן "לא נמצא").

## שמות עמודות שונים בקטלוג?

הסקריפט מזהה שמות נפוצים אוטומטית. אם ייצוא הקטלוג שלך משתמש בשם אחר
למפתח הפריט, אפשר לעקוף:

```bash
--catalog-key "קוד פריט"    # שם עמודת המפתח בקטלוג
--current-key "מק\"ט"        # שם עמודת המפתח ברשימת המבצעים
```

## העדכון החודשי שלך = 3 צעדים

1. עדכן את רשימת המבצעים של החודש (העתק את של החודש שעבר, שנה מה שהשתנה).
2. ייצא קטלוג מוצרים עדכני.
3. הרץ את הפקודה עם `--current` החדש ו‑`--previous` של החודש שעבר.

> הערה: קבצי הפלט נשמרים תחת `data/` שחסום ל‑git (מידע עסקי). הקוד עצמו
> והדוגמאות נשמרים ב‑git.

## 📑 סידור קטלוג לפי קטגוריות — `organize_catalog.py`

לוקח גיליון קטלוג מלא (כמו "מבצעים ספטמבר 26") ומסדר אותו: מקבץ לפי
**קטגוריות ראשית**, וכך שבתוך כל קטגוריה הפריטים המסומנים **SUN / STAR**
(עמודת `priority`) מופיעים ראשונים. סדר הקטגוריות = סדר ההופעה המקורי,
ו‑`#N/A`/ריק בסוף. נכתב קובץ חדש — המאסטר לא נגע.

```bash
python -m promotions.organize_catalog \
    --input "קובץ המבצעים.xlsx" \
    --sheet "מבצעים ספטמבר 26" \
    --out   "data/מבצעים ספטמבר מסודר.xlsx" \
    --month ספטמבר
```

הפלט: גיליון RTL עם פס קטגוריה בהיר בתחילת כל קבוצה, הדגשת sun/star,
כותרת מוקפאת, ועמודות הקטלוג האמיתיות (עמודות ריקות/מקרא צדדי מושמטות).
דגל `--no-visuals` מסדר בלי צביעה.

> **חשוב לטעינה בקטלוג ה-HTML:** הפלט נכתב עם **שורת הכותרת בשורה 1**
> (בלי כותרות-על מעליה), כי SheetJS מזהה עמודות לפי השורה הראשונה. קובץ עם
> כותרות-על למעלה (כמו הגיליון המקורי "מבצעים ספטמבר 26") לא ייטען נכון
> בגרסה הישנה של ה-HTML.

## 🌐 קטלוג ה-HTML — `catalog.html`

קטלוג ויזואלי (כרטיסיות מוצר, תמונות, עגלה, הצעת מחיר) שטוען קובץ אקסל דרך
"בחר קובץ", עם **סידור ידני מובנה** (גרירת קטגוריות/פריטים + צבעים) שנשמר
בדפדפן (localStorage). זה המקום שבו נעשה הסידור הידני — לא באקסל.

הקובץ שנטען צריך לכלול (בשורת הכותרת): `מפתח פריט`, `שם פריט`, `בר קוד`,
`קטגוריות ראשית`, `priority`, `מחיר מכירה`, `מבצעים`, `SNAPSHOT-55` (מלאי;
פריט עם מלאי 0 מסונן), ועוד. הפלט של `organize_catalog.py` תואם.

**שדרוג שנוסף:** `loadXLS` מזהה אוטומטית את שורת הכותרת (מדלג על כותרות-על
עד השורה שמכילה "מפתח פריט"), כך שכל קובץ נטען — עם או בלי כותרות-על.
