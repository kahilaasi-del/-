# חשבשבת BI — משיכת נתונים, ניתוח ודשבורד

פרויקט למשיכת נתונים מ‑**חשבשבת SQL** (SQL Server), ניתוח עסקי, ובניית דשבורד ויזואלי.

המטרות הנתמכות:

- 🎯 **יעדים ומעקב מכירות** — מעקב אחרי פריטים נמכרים, הפצת מוצר לסוכן.
- 💰 **ניתוח כספי ורווחיות** — מכירות, רווחיות לפי לקוח/פריט/סוכן, מגמות.
- 📉 **גיול חובות ותזרים** — יתרות חייבים/זכאים, תחזית תזרים.
- 📊 **דשבורד ויזואלי** — גרפים אינטראקטיביים ו‑KPI.
- 🔎 **בדיקות ואנומליות** — איתור טעויות, כפילויות, רשומות חריגות.

---

## ⚠️ קרא קודם — מגבלת רשת

חשבשבת יושבת על SQL Server ברשת הפנימית שלך. לכן את הקוד **מריצים על מחשב שיש לו גישה
לשרת** (המחשב שעליו חשבשבת, או מחשב באותה רשת). הסביבה הענן של Claude לא מגיעה לשרת שלך.

זרימת העבודה:

1. אתה מריץ אצלך את שלבי המשיכה והניתוח.
2. הפלטים (CSV/JSON) יכולים להישלח ל‑Claude לניתוח מעמיק נוסף.
3. הדשבורד רץ מקומית בדפדפן שלך.

---

## מסלול חלופי — בלי SQL, מייצוא H-BI ⭐

אם אין גישת SQL, אפשר לעבוד ישירות מקבצים שמייצאים מ‑**חשבשבת H-BI** (עם ההתחברות
הרגילה שלך, בלי IT). מייצאים שני קבצים:

1. **מכירות** (CSV) — מכירות חודשיות לפי לקוח (כולל "מפתח חשבון").
2. **מסלול מועשר** (XLSX) — לקוחות עם עיר/כתובת/אזור/סטטוס (כולל "מס' לקוח").

ואז פקודה אחת מפיקה הכל:

```bash
python -m src.hbi_report --sales מכירות.csv --route מסלול.xlsx --out data/agent31 --title "סוכן 31"
```

תוצרים ב‑`data/agent31/`:
- `merged.csv` — נתונים מאוחדים (מכירות + כתובות + סטטוס)
- `report.xlsx` — חוברת עבודה לשטח: סקירה · לפי אזור · בסיכון לפעולה · מסלול לפי יום · כל הלקוחות
- `dashboard.html` — דשבורד ויזואלי עצמאי (נפתח בכל דפדפן)

"פעיל" מוגדר כ‑קנייה ב‑60 הימים האחרונים (ניתן לשינוי עם `--current-month`).

## התקנה

### דרישות מקדימות

- Python 3.10+
- **ODBC Driver 17/18 for SQL Server** מותקן במערכת
  ([הורדה מ‑Microsoft](https://learn.microsoft.com/sql/connect/odbc/download-odbc-driver-for-sql-server))
- הרשאת **קריאה** (Read‑Only) למסד הנתונים של חברת חשבשבת הרלוונטית

### שלבים

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

pip install -r requirements.txt

# העתק והגדר את פרטי החיבור (לא נשמר ב-git):
copy .env.example .env      # Windows
# cp .env.example .env      # Linux/Mac
# ערוך את .env עם פרטי השרת, מסד הנתונים, משתמש וסיסמה
```

## שימוש — לפי הסדר

### שלב 1: בדיקת חיבור

```bash
python -m src.db --test
```

### שלב 2: גילוי סכימה (חשוב! עושים פעם אחת)

סורק את מסד הנתונים ומפיק קטלוג טבלאות/עמודות + ניחוש חכם של הטבלאות
החשובות (מכירות, כרטסת, מלאי, חשבונות).

```bash
python -m src.discover_schema
```

תוצרים ב‑`data/`:

- `catalog.json` — כל הטבלאות והעמודות (מספרי שורות, סוגי נתונים).
- `schema_report.md` — דוח קריא + מועמדים לכל דומיין.

**שלח לי את `schema_report.md`** ואמלא יחד איתך את `config/mapping.yaml`.

### שלב 3: מיפוי

```bash
copy config\mapping.example.yaml config\mapping.yaml
# ערוך לפי דוח הסכימה
```

### שלב 4: משיכת נתונים

```bash
python -m src.extract              # מושך את כל הדומיינים המוגדרים
python -m src.extract --domain sales
```

הנתונים נשמרים ב‑`data/extract/` (Parquet + CSV).

### שלב 5: ניתוח

```bash
python -m src.analysis --report all
```

### שלב 6: דשבורד

```bash
streamlit run dashboard/app.py
```

## מבנה הפרויקט

```
├── src/

│   ├── db.py              # חיבור מאובטח ל-SQL Server

├── config/
│   └── mapping.example.yaml
├── dashboard/
│   └── app.py             # דשבורד Streamlit
├── sql/                   # שאילתות SQL לעריכה ידנית
├── data/                  # פלטים (לא נכנס ל-git)
├── requirements.txt
└── .env.example
```

## אבטחה

- פרטי החיבור נמצאים ב‑`.env` בלבד — **לא נכנס ל‑git** (ראה `.gitignore`).
- כל השאילתות הן **קריאה בלבד** (`SELECT`). אין כתיבה למסד הנתונים של חשבשבת.
- מומלץ להשתמש במשתמש SQL ייעודי עם הרשאת `db_datareader` בלבד.
